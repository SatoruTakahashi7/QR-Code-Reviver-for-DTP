# QRコードを復活させるやつ

QRコード画像を読み取り、DTP向けに安全なPDF/SVGとして再構成する macOS アプリです。

## 概要

「QRコードを復活させるやつ」は、歪み・ボケ・低解像度などで扱いにくくなったQRコード画像を、DTP作業で使いやすい形に整えるためのアプリです。

主に InDesign / Illustrator での配置・確認を想定しています。

## 主な機能

- QRコード画像の読み取り
- 再生成QRの作成
- 復元候補QRの作成
- 判定が怪しいセルの可視化
- 復元候補QRの手動修正
- 1つ戻る / ⌘Z
- 正面化元QRとのパタパタ比較
- 復元QR / 再生成QR のPDF書き出し
- 復元QR / 再生成QR のSVG書き出し
- クワイエットゾーン4セル込み
- セルサイズ 0.25mm / 0.28mm

## 書き出し形式

### PDF

InDesign配置向けの本命形式です。  
QRコードをベクターとして書き出します。

### SVG

Illustratorで確認・編集するための補助形式です。

## 使い方

1. QRコード画像をドラッグ＆ドロップします。
2. 読み取り結果を確認します。
3. 復元候補QRと再生成QRを確認します。
4. 必要に応じて復元候補QRを編集します。
5. 復元QRまたは再生成QRをPDF/SVGで書き出します。

## 注意

- 結果に関しては一切の保証はできません。
- 本アプリの読み取り結果および使用結果について、正確性・完全性は保証できません。
- 書き出したQRコードは、必ず実機またはQRコードリーダーで読み取り確認してください。
- 復元QRは、元画像由来のセル配置をもとに作成しますが、元画像の品質によっては正しく復元できない場合があります。
- 復元候補QRが元画像の内容と一致しない場合、復元QRとしては書き出せません。
- 入稿用途では、PDF形式の使用を推奨します。
